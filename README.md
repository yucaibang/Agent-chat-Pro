# Agent-chat-Pro
Agent Chat Pro 是一款面向 Windows 桌面的三模式 AI 聊天客户端：云端 AI 直连十家服务商、SSH 远程连远端机器上的 Claude Code、本机引擎三线并行，装进同一个界面。围绕核心长出整套周边：带工具循环的云办公（Docker 沙箱隔离执行）、Agent plan 面板、ask_user 选择卡、思考挡位调节、后台任务切对话无缝衔接、开发面板实时观察 AI 改动、N2N 虚拟专网体检与一键部署。安全侧走防破解构建管线：密钥 safeStorage 加密、CSP 零外发请求、ASAR 完整性校验、代码混淆加全量守门测试。本仓库公开源码仅用于审阅、学习与安全检验，未经授权不得商用分发；安装包见 Releases

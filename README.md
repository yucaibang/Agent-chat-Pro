## ✨ 核心特性

### 🌐 三模式连接
- **SSH 远程** — 连接 NAS/服务器上的 Claude Code，远程开发
- **云端 AI** — 无需本地 CLI，直连 AI 服务商聊天
- **本机运行** — 使用本机 Claude Code

## 📥 下载安装

前往 [Releases](../../releases) 页面下载最新版安装包。

**系统要求**：Windows 10/11（64 位）

**安装步骤**：
1. 下载 `Agent Chat Pro-x.x.x-Setup.exe`
2. 双击运行安装向导
3. 选择安装目录，完成安装
4. 启动后选择「云端 AI」模式
5. 选择服务商，输入 API 密钥即可开始聊天

---

## 🚀 快速开始

### 云端 AI 零门槛
1. 启动 → 选择「云端 AI」模式
2. 服务商选「智谱 AI」
3. [点击免费注册](https://open.bigmodel.cn/user/apikey) → 创建密钥
4. 粘贴密钥 → 开始聊天 🎉

### SSH 远程
1. 选择「SSH 远程」模式
2. 填写 NAS 地址、账号、密码
3. 连接后即可远程使用 Claude Code
